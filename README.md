# Project archive

This orphan `trash` branch keeps notes and reviewed screenshots from ideas and experiments separate from `main`. It is an archive, not a source-code branch: do not merge it into `main`.

Created: 2026-10-27.

## Add an entry

1. Copy [TEMPLATE.md](TEMPLATE.md) to `ideas/YYYY-MM-DD-short-name/README.md`.
2. Record the purpose, date, status, reason, findings and source references. Use `geprobeerd` (tried), `geparkeerd` (parked) or `gestopt` (stopped).
3. Only after a privacy review, place screenshots in that entry's `screenshots/` folder and link them with relative Markdown paths. Check for secrets, private conversations, personal details and machine addresses before committing or publishing. A branch in a public repository is public too.
4. Add the entry to the index below and commit only the intended archive files on `trash`. Publishing is a separate, deliberate action.

Keep Markdown and images as ordinary files, not ZIPs. Reference source-code commits rather than copying the application here. Conversation references help local readers but do not make those conversations publicly accessible.

Archiving does not authorize deleting files, importing old material automatically or restarting stopped work. Keep this branch in its own persistent worktree; never switch the live application checkout to it. A short lesson may live in project memory with an archive reference, but archive contents are not automatically added to agent context.
